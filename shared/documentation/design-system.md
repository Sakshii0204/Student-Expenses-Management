# Design System — Premium Finance Dashboard

## Visual Hierarchy & Theme Tokens
- **Backgrounds**:
  - Primary Page: `#f8fafc` (Slate 50)
  - Card & Container Surface: `#ffffff` (White)
  - Dark Nav/Sidebar: `#0f172a` (Slate 900)
- **Primary / Brand Colors**:
  - Deep Navy Accent: `#1e293b` / `#0f172a`
  - Emerald Green Action / Growth: `#059669` (Emerald 600) / Hover: `#047857`
  - Subtle Danger / Expenses: `#dc2626` (Rose 600)
  - Text Primary: `#0f172a` (Slate 900)
  - Text Muted: `#64748b` (Slate 500)
  - Border Lines: `#e2e8f0` (Slate 200)

## Component Standards
- **Buttons**:
  - Primary: Emerald green button, white text, subtle shadow, rounded-lg.
  - Secondary: White background, slate border, slate text.
  - Danger: Rose background, subtle hover effect.
- **Metrics Cards**:
  - White surface, 1px slate-200 border, 16px padding, subtle shadow-sm.
  - Clear label in slate-500, big bold currency figure, trend tag.
- **Forms**:
  - Rounded-lg inputs, 1px border, smooth focus ring with navy/emerald tint.
  - Inline error labels with descriptive feedback.
- **Tables**:
  - Clean row striping, crisp borders, right-aligned monetary values.
